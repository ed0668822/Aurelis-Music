Referencia: BitChord b690dc1. Identidad y tipografías autorizadas son diferencias
aprobadas. La presencia de un archivo, compilación o captura aislada no es paridad.
En B00 todas las comprobaciones visuales nuevas quedan pendientes.

Por elemento guardar referencia visual verificable, mediciones, archivo/commit,
ruta activa, dataset, interacción, captura y diferencias autorizadas. Obtener una
referencia ejecutable/capturas verificadas antes de cerrar fidelidad; no inventar
porcentajes de semejanza ni usar pantallas remotas como datos de producción.

Probar claro/oscuro, 320/360/600dp, vertical/horizontal, safe areas, navegación del
sistema, texto grande/TalkBack, contraste y reducir movimiento/desenfoque. Medir
posiciones y dimensiones respecto al origen. Un control debe ejecutar su acción
o explicar con precisión una incompatibilidad real. No simplificar por comodidad.
Las capturas anteriores de ../screenshots son evidencia histórica de Aurelis,
no sustituyen referencias ejecutables de BitChord ni pruebas de esta beta.
